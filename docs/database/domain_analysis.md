# Анализ предметной области и сущности базы данных

Предметная область — учёт силовых тренировок: пользователь планирует тренировки, добавляет в них упражнения из справочника и записывает подходы с повторениями и весом. Источник требований — [техническое задание](https://github.com/KirillS997/workout-tracker-srs/wiki/Техническое-задание).

## 1. От требований к данным

| Требование ТЗ | Что нужно хранить | Сущность |
|---|---|---|
| 2.1. Создавать тренировку с названием и датой | Название, плановая дата | Workouts |
| 2.1. Добавлять в тренировку упражнения из справочника | Какие упражнения входят в тренировку и в каком порядке | Workout_Exercises |
| 2.2. Добавлять подходы с повторениями и весом, отмечать подход выполненным | Номер подхода, повторения, вес, отметка о выполнении | Sets |
| 2.2. Завершать тренировку; 2.5. Измерять длительность | Время начала и время завершения | Workouts |
| 2.3. Справочник упражнений с группой мышц | Название упражнения и его группа мышц | Exercises, Muscle_Groups |
| 2.3. Собственные упражнения пользователя | Кто добавил упражнение | Exercises |
| 2.4, 2.5. История, рекорды, тоннаж, графики | Ничего нового: всё вычисляется из подходов и тренировок | — |
| 4. Выбор тёмной или светлой темы сохраняется | Тема оформления | Users |
| 2.6. Экспорт и импорт всех данных пользователя | Чьи это данные | Users |

Текущий прототип хранит данные одного пользователя в браузере. В базе данных пользователь выделен в отдельную сущность, чтобы одна база могла обслуживать нескольких людей.

## 2. Сущности и атрибуты

| Сущность | Что описывает | Атрибуты |
|---|---|---|
| **Users** | Пользователь приложения | `user_id`, `username`, `email`, `theme`, `created_at` |
| **Muscle_Groups** | Группа мышц | `muscle_group_id`, `name` |
| **Exercises** | Упражнение из справочника | `exercise_id`, `name`, `created_at`, `muscle_group_id`, `user_id` |
| **Workouts** | Тренировка | `workout_id`, `name`, `workout_date`, `started_at`, `finished_at`, `created_at`, `updated_at`, `user_id` |
| **Workout_Exercises** | Упражнение в составе тренировки | `workout_id`, `exercise_id`, `position` |
| **Sets** | Подход | `set_id`, `set_number`, `reps`, `weight_kg`, `is_completed`, `workout_id`, `exercise_id` |

## 3. Связи

| Связь | Тип | Пояснение |
|---|---|---|
| Users → Workouts | один-ко-многим | У тренировки один владелец, у пользователя много тренировок |
| Muscle_Groups → Exercises | один-ко-многим | В ТЗ у упражнения одна группа мышц |
| Users → Exercises | один-ко-многим, необязательная | Собственное упражнение принадлежит пользователю; у предустановленного владельца нет |
| Workouts ↔ Exercises | многие-ко-многим | В тренировке много упражнений, упражнение входит во много тренировок. Реализуется таблицей Workout_Exercises |
| Workout_Exercises → Sets | один-ко-многим | У упражнения в тренировке несколько подходов |

## 4. Правила предметной области

| Правило | Источник | Как обеспечивается в базе |
|---|---|---|
| Одно упражнение можно добавить в тренировку только один раз | задача #2 | Составной первичный ключ `(workout_id, exercise_id)` |
| Повторения — целое число от 1 до 999 | ТЗ, раздел 3 | `CHECK` на `Sets.reps` |
| Вес — от 0 до 500 кг с шагом 0,5 | ТЗ, раздел 3 | `CHECK` на `Sets.weight_kg` |
| Подход может быть пустым, пока не выполнен | задача #17 | `reps` и `weight_kg` допускают `NULL`; у выполненного подхода они обязательны |
| Подход существует только у упражнения, которое есть в тренировке | задача #3 | Внешний ключ `Sets → Workout_Exercises` |
| При удалении тренировки удаляются её упражнения и подходы | ТЗ, 2.1 | `ON DELETE CASCADE` |
| Группа мышц — одна из шести | задача #8 | Отдельная таблица `Muscle_Groups` и внешний ключ |

## 5. Что намеренно не хранится

Эти значения вычисляются запросом. Если хранить их в таблицах, они могут разойтись с исходными данными.

| Значение | Как получается |
|---|---|
| Статус тренировки | Из `started_at` и `finished_at`: запланирована, идёт или завершена |
| Длительность тренировки | `finished_at − started_at` |
| Тоннаж | Сумма `reps × weight_kg` по выполненным подходам |
| Максимальный вес и 1ПМ | Максимум по подходам упражнения; 1ПМ = вес × (1 + повторения / 30) |
